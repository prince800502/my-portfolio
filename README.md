# Prince Singh Chauhan — Portfolio v2

A responsive portfolio made with plain HTML, CSS, and JavaScript. It includes the generated hero portrait in `assets/`.

## Run it
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html` to open it in your browser.
4. No npm install or build step is required.

## Main files
- `index.html` — page content and links
- `style.css` — styling, responsive layouts, and animation
- `script.js` — mobile navigation, scroll progress, and reveal animations
- `assets/prince-hero.*` — generated portfolio portrait

## Before publishing
- Check the links and update any details that change.
- Add a real CV file if you later want a downloadable resume button.
